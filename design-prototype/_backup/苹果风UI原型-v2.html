苹果官网风 · 重设计

不再做 iOS App 卡片风——改为直接引用 Apple.com 的官网设计语言：全出血明暗交替、超大标题、发丝线、单一蓝色。

01全出血明暗交替 tile

每个视图是一块 full-bleed 区块，背景在 深色↔白色↔浅灰 之间切换——颜色切换本身就是分隔符，与 apple.com 产品页一致。

02超大标题排印

hero 标题 46px / 600 字重 / 行高 1.07 / -0.03em 负字距（官网规范：56px / 600 / 1.07 / -0.28px），小字眉标 13px 半宽字距，正文 16px 冷灰。

03发丝线，不是卡片

列表一律 1px #E8E8ED 发丝线分隔，无边框无阴影；目标用「淡色圆角面板」#F5F5F7 / 22px——对应官网 store 卡片，是唯一带圆角的大面。

04单一 Action Blue

全界面唯一交互色 #0066CC（官网 Action Blue）：胶囊按钮、勾选、链接、选中 Tab。无第二品牌色。

05UI 隐退，内容说话

顶部导航透明无底、无阴影，底部 tab 只有一条发丝线；小蓝药丸是唯一按钮语法（11px×26px 圆角 99px）。

相对 v1 原型的改动

  • 去毛玻璃、去卡片阴影、去 20px 圆角卡片——全部换发丝线
  • hero 区改官网式大标题（居中 + kicker + 胶囊 CTA），每屏明暗交替
  • 目标卡片 → 淡色圆角大面板（store 语言）
  • 强调色改为官网 Action Blue #0066CC
  • 底部 tab 去毛玻璃块，只留发丝线上分隔
  • 想法/周/月视图重排为 hero + 发丝线列表结构
设计语言依据：VoltAgent awesome-design-md/apple、design.withfudge.com 对 apple.com 的分析、Apple.com.cn 官网（2026-10 抓取）。这是视觉原型（示例数据）。
