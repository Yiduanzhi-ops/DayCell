重设计思路

把 DayCell 从"工具卡片"拉向"每日生活界面"——沿用现有五视图与全部功能，只重做视觉语言与交互质感。

1毛玻璃层级

顶部导航与底部 Tab 改为 backdrop-filter: blur(22px) 半透明材质，内容滚动穿过而不是被压扁。菜单以毛玻璃 sheet 从右上角按钮原地展开，符合"从哪里来，回哪里去"。

2大标题排印

每屏一个大标题（33px、letter-spacing:-0.025em、行高 1.08），层级靠字重与负字距建立，不靠加粗描边。正文保持 0 字距——大小标题各用各的 tracking。

3单一强调色

全局只保留一个强调色（浅色 #0071E3 / 深色 #0A84FF）：勾选、进度、选中 Tab、按钮。其余全部交给黑白灰 4 级文字层级，颜色克制才显得高级。

4spring 动效

视图切换、菜单弹出用 cubic-bezier(0.32,0.72,0,1)（近似 iOS 弹簧），按下即反馈（:active 缩放）。实现时用 spring 库（Motion）替换 CSS transition，支持中途打断与速度继承。

5深浅双主题

浅色底 #F5F5F7 深色底 #000，同一套 token 变量自动切换，含毛玻璃与阴影的暗色变体。可保留菜单里的「夜间模式」开关。

相对现有 UI 的改动

  • 顶部工具栏 → 透明毛玻璃，只留 logo 与圆角菜单按钮
  • 卡片：去灰边硬线，改为毛玻璃 + 大圆角（20px）+ 轻阴影
  • 待办/习惯：去复选框边框，改用细圆点与圆形勾选
  • 分隔：用间距分组替代分割线，信息密度降低 30%
  • 全部图标重绘为统一线性 SVG，粗细 1.7
  • 月视图纪念日：格内淡蓝底 + 小字名称，支持换行展示
这是视觉原型（示例数据）。确认方向后，可逐步把 token 与组件落地到 DayCell 源码，再整体替换样式层。
